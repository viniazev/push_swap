# ft_printf

## Description

This project implements a simplified version of the standard C `printf` function, commonly known as `ft_printf`. The goal is to support formatted output for characters, strings, integers, unsigned integers, hexadecimal values, and pointers, while maintaining behavior similar to the C standard library function. This project is designed to deepen understanding of variadic functions, format parsing, and low-level output handling in C.

## Instructions

- Compile the project using the provided `Makefile`:
  - `make`
- This produces the `libftprintf.a` library file and the `ft_printf` executable if present.
- Run the executable or use the compiled library in your own programs for formatted output tests.
- Clean generated files with:
  - `make clean`
- Remove all compiled files and archives with:
  - `make fclean`
